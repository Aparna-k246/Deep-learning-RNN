# 🧠 Simple RNN - IMDB Sentiment Classification 🎬

Welcome to the **Simple RNN** project! This repository demonstrates how to build and train a **Recurrent Neural Network (RNN)** on the **IMDB Movie Review Dataset** to perform sentiment classification (positive/negative). Great for showcasing NLP and deep learning skills to recruiters. 💼

---

## 📁 Project Structure

```
Simple RNN/
├── embedding.ipynb           # 🔤 Word embeddings visualization & prep
├── main.py                   # 🚀 Script for end-to-end RNN training
├── prediction.ipynb          # 🔍 Inference on sample reviews
├── simple_rnn_imdb.h5        # 💾 Trained RNN model weights
└── simplernn.ipynb           # 📘 Core notebook for training & eval
.gitignore
README.md
requirements.txt              # 📦 Required Python libraries
```

---

## 🚀 What You’ll Learn

✅ Building a sentiment classifier using RNN  
✅ Handling sequence data (tokenization, padding, embedding)  
✅ Saving/loading models with `.h5`  
✅ Making predictions on new reviews  

---

## 🧪 How to Run

1. 📦 Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

2. ▶️ Run the training
   ```bash
   python main.py
   ```

3. 🧪 Test predictions using:
   - `prediction.ipynb` (interactive)
   - Or load `simple_rnn_imdb.h5` in your app
